2. `focusModule` 会先清 `focusedProcessId`；另外「LOD=0 自动清焦点」会把飞入动画开头那几帧当成缩回全局，导致深链焦点被抹掉 → 加 `navUntil` 时间戳，动画期间不清。
3. `useNavigate` / `CommandPalette` 都依赖 `useReactFlow`，**必须放在 ReactFlowProvider 之内**；App 里调用 `useHashRoute` 会直接报错 → 拆出 `<Shell>`。
4. 流程取景：单行泳道的卡片是垂直居中的（`stepYBase` 返回 (LANE_H-STEP_H)/2），按泳道高度取景会把内容压到下半屏 → 改成按「卡片带」算 rect。
5. 泳道间距试过「均匀分布」把 3 条流程压到 385px，直接和 520 高的泳道重叠 → 回滚为固定 550，接受 2 条流程模块底部留白。
6. 卡片 2 行标题会挤压 meta/对象数 → 标题 19px + clamp 2 行，对象数进正常流（不用 absolute）。
7. 悬停卡对象过多会顶出屏幕 → 最多 5 个 + 「另有 N 个」，正文 clamp 4 行，卡高上限 min(78vh, 600)。
