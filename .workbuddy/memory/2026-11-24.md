# 2026-11-24

## SAP Map 项目启动（架构设计阶段）

**需求**：一个面向人的 SAP 多模块知识库 Canvas。模块 → 业务流程 → 开发对象，通过缩放切换层级，悬停展示开发对象与示例代码。纯前端，未来发 GitHub Pages，当前只本地开发。

**已完成的决策**
- 定位区分：画「知识结构图」（模块/流程/步骤/对象，稳定布局）而非「实例数据图」（单据流，力导向）。这是与现有开源 SAP 图项目的差异点。
- 四层语义缩放 L0 星系 / L1 模块 / L2 流程 / L3 步骤 / L4 对象，阈值集中在 `src/canvas/lod/lod.config.ts`。
- 数据模型关键点：`Step` 与 `Process` **多对多**，流程只存 step id 引用，内容单点维护 —— 解决"流程重复出现"的网状问题。跨模块用 `GhostAnchor` 幽灵锚点互跳。
- 技术选型：Vite + React 18 + TS + React Flow 12（自定义节点是 React 组件，适合信息卡片）+ elkjs 布局 + motion + zustand + zod + Prism(abap)。排除 Cytoscape/G6（自定义节点表达力不足）。
- 目录原则：`src/data`（内容资产）与 `src/canvas`（渲染引擎）彻底解耦；`graph/` 纯函数与 `canvas/` 组件分离。
- ID 规范：`sd` / `sd.o2c` / `sd.o2c.create-order` / `bapi.SALESORDER_CREATEFROMDAT2`；深链用 hash 路由 `#/sd/o2c/create-order`。

**已创建**
